This repository contains **highly experimental software exploring concept formation, reinforcement, and cognition-like behaviors**.

## 🔒 SAFE OPERATING GUIDELINES (MINIMUM)

Before running *any* experiment:

- Enable **output gating** (do not allow unrestricted console or speech output)
- Enable **logging** (file-based, not stdout only)
- Limit input modalities (start with one at a time)
- Use **toy datasets** or controlled stimuli only
- Run with **short sessions** and frequent resets
- Observe behavior before adding new features

If the system begins to:
- spam output
- loop obsessively
- escalate novelty seeking
- show instability

**Stop the experiment immediately and review logs.**
